# Agent Rules / Agent 规则

本目录承载项目详细规则，根目录 `AGENTS.md` 只负责入口与加载时机。 This directory contains detailed project rules; root `AGENTS.md` contains only the entry point and loading timing.

按 `.agents/rules/index.md` 的任务映射按需读取，避免复制规则。 Load files on demand using the task map in `.agents/rules/index.md` instead of copying rules into new instruction files.
