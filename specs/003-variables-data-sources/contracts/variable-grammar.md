# 契约：`${}` 引用文法（冻结）

本文法一旦发布即**不可修改**——既有模板的内容按它解释，改动会静默改变已有标签的含义。
所有取舍的理由见 `docs/variables-and-data-sources.md` 第 2 节。

## 词法

```
内容      := (字面片段 | 引用 | 转义)*
引用      := "${" 名称 "}"
转义      := "$$"                         → 输出字面的 "$"
名称      := 除 "}" 外的任意字符，至少一个
```

- 名称的**首尾空白被去除**；去除后为空则该引用无法解析（FR-009a）
- **单层命名空间**：一个名称可能指向设计期常量、自增变量，或所绑数据源的一列。
  没有路径、没有分隔符、没有引号段
- 因此 `.` 在名称中是普通字符：`${单价.含税}` 直接指向名为「单价.含税」的列
- 转义的是**美元符号**而非整个 `${`。`$${` 于是读作「转义的 `$`」+ 字面 `{`，仍然输出
  `${`（FR-012 不变）；而 `$$${price}` 读作「转义的 `$`」+ 引用，输出 `$19.90`

  **修订（2026-08-22，实现期）**：原规则是 `$${` → `${`，边界表里的
  `$$${sku}` → 字面 `${` + 引用 `sku` **算术上不可能**——产出需要消耗 9 个字符，而输入
  只有 8 个。契约测试第一次跑就抓到了它。

  修正时顺带发现原规则让**价格标签无法表达**：`$${price}` 会印出字面的 `${price}`，
  而这是一次「印出来才发现」的错误。改为转义美元符号之后，`$${` 的行为完全不变，
  但 `$$${price}` 变得可写。

## 为什么没有 `${源.列}`

两级路径只有在一个设计能引用多个数据源时才携带信息。FR-029 规定一个设计最多绑定一个
数据源，FR-030 拒绝跨表关联——前缀于是恒等于「那个唯一的数据源」，是一段永远算得出、
却要求用户每次手写的冗余。

去掉它连带消除了三件事：路径分隔规则、为消解分隔符而存在的引号段、以及「列名不得含
点号」这条对用户表格的无理要求。

**曾被否决的写法**（理由不变）：`${A}.${B}` 与 `${A}.{B}` 都会让下面两行被误解析，
所以引用的边界必须完整落在一对花括号内：

```
版本 ${major}.${minor}     ← 两个普通变量，中间一个字面点号
批号 ${lot}.{已校验}       ← 一个变量 + 字面文本
```

## 名称的归属

数据源列**不声明**（`Template.variables` 只登记常量与自增）。求值时按此顺序查找：

1. `Template.variables` 中的常量与自增
2. 所绑数据源（`Template.dataSourceId`）当前行的列

**两者重名 MUST 报错，MUST NOT 定优先级**（FR-009b）。静默的优先级规则属于「看起来
没问题，直到有人往表里加了一列」那一类缺陷：加列的人不会知道自己遮蔽了某个设计的常量。

## 解析结果

```
type Segment =
  | { kind: 'literal'; text: string }
  | { kind: 'ref'; name: string }
  | { kind: 'unterminated'; text: string }        // ${sk —— 尚未写完
```

`unterminated` 是**正常状态**而非错误：它是有人正在输入 `${sku}` 的中途。调用方
MUST 把它当作字面文本处理，且 MUST NOT 因此报错（FR-013、FR-016）。

## 求值

| 情形 | 编辑器 | 打印 |
|---|---|---|
| 名称可解析 | 代入值 | 代入值 |
| `unterminated` | 原样显示 | 原样输出 |
| 已闭合但名称不存在 | 原样显示 **+ 阻塞性问题** | 拒绝（不会走到这一步） |

编辑器代入的值：常量取其值；自增取序号池的下一个号；数据源列取该列首行值（FR-015）。

## 边界用例（契约测试必须覆盖）

| 输入 | 期望 |
|---|---|
| `版本 ${major}.${minor}` | 两个引用，中间字面 `.` |
| `批号 ${lot}.{已校验}` | 一个引用，其后字面 `.{已校验}` |
| `$${sku}` | 字面 `${sku}`，不是引用（`$$`→`$`，其后 `{sku}` 是字面） |
| `$$${sku}` | 字面 `$` + 引用 `sku`（价格标签就靠这条） |
| `$$` | 字面 `$` |
| `${ sku }` | 引用 `sku`（首尾空白去除） |
| `${}` | 无法解析 |
| `${ }` | 无法解析（去空白后为空） |
| `${sk` | `unterminated` |
| `${单价.含税}` | 引用 `单价.含税`（点号是普通字符） |
| `${a.b.c}` | 引用 `a.b.c` |
| `${收件 人}` | 引用 `收件 人`（内部空格合法） |
| `${说"明"}` | 引用 `说"明"`（引号是普通字符） |
| `价格 $100` | 全部字面（`$` 后非 `{`） |
