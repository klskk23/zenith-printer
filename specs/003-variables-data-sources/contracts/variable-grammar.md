# 契约：`${}` 引用文法（冻结）

本文法一旦发布即**不可修改**——既有模板的内容按它解释，改动会静默改变已有标签的含义。
所有取舍的理由见 `docs/variables-and-data-sources.md` 第 2 节。

## 词法

```
内容      := (字面片段 | 引用 | 转义)*
引用      := "${" 路径 "}"
转义      := "$${"                        → 输出字面的 "${"
路径      := 名称 | 名称 "." 段
段        := 名称 | '"' 任意非引号字符* '"'
名称      := 除 "." "}" '"' 外的任意字符，至少一个
```

- 名称的**首尾空白被去除**；去除后为空则该引用无法解析（FR-009a）
- `.` 只在**路径的第一次出现**处分段；`${a.b.c}` 解析为源 `a`、列 `b.c`
- 引号段用于列名含点号：`${订单表."单价.含税"}`
- 引号内暂不支持转义引号（`spec.md` Assumptions 已记录）

## 解析结果

```
type Segment =
  | { kind: 'literal'; text: string }
  | { kind: 'ref'; name: string }                 // ${sku}
  | { kind: 'ref'; source: string; column: string } // ${订单表.收件人}
  | { kind: 'unterminated'; text: string }        // ${sk —— 尚未写完
```

`unterminated` 是**正常状态**而非错误：它是有人正在输入 `${sku}` 的中途。调用方
MUST 把它当作字面文本处理，且 MUST NOT 因此报错（FR-013、FR-016）。

## 求值

| 情形 | 编辑器 | 打印 |
|---|---|---|
| 引用可解析 | 代入值 | 代入值 |
| `unterminated` | 原样显示 | 原样输出 |
| 已闭合但名称/列不存在 | 原样显示 **+ 阻塞性问题** | 拒绝（不会走到这一步） |

编辑器代入的值：常量取其值；自增取序号池的下一个号；数据源列取该列首行值（FR-015）。

## 边界用例（契约测试必须覆盖）

| 输入 | 期望 |
|---|---|
| `版本 ${major}.${minor}` | 两个引用，中间字面 `.` |
| `批号 ${lot}.{已校验}` | 一个引用，其后字面 `.{已校验}` |
| `$${sku}` | 字面 `${sku}`，不是引用 |
| `$$${sku}` | 字面 `${` + 引用 `sku`（`$$` 先配对） |
| `${ sku }` | 引用 `sku`（首尾空白去除） |
| `${}` | 无法解析 |
| `${sk` | `unterminated` |
| `${a.b.c}` | 源 `a`，列 `b.c` |
| `${订单表."单价.含税"}` | 源 `订单表`，列 `单价.含税` |
| `${收件 人}` | 引用 `收件 人`（内部空格合法） |
| `价格 $100` | 全部字面（`$` 后非 `{`） |
