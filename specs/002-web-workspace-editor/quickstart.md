# Quickstart：前端工作区与标签编辑器重构

**Feature**: `002-web-workspace-editor`

前置条件与 001 相同（Node ≥ 26、已执行 `npm install`、已获取打包字体）。
本文只列**本功能相关**的验证步骤。

---

## 0. 环境自检

```bash
node --version                 # 需 ≥ 26
ls fonts/full/                 # 需含 NotoSansCJK-Regular.ttc 等 4 个文件

# MANIFEST 里是裸文件名，字体在 fonts/full/ —— 必须在该目录下校验。
# 从仓库根目录执行会全部报 "FAILED open or read"，那是路径不对，不是字体损坏。
(cd fonts/full && sha256sum -c ../MANIFEST.sha256)
npm run typecheck && npm run lint && npm test
```

字体缺失时渲染出的是空白而非报错——这在本项目中已经骗过一次测试，
**动手前先确认这一步通过**。

## 1. 验证渲染缺陷已修复（US1，无需打印机）

### 1.1 二维码不再是条码

```bash
npm run cli -- render-test --element qrcode --content "https://example.com" -o /tmp/qr.png
```

**期望**：`/tmp/qr.png` 是二维码矩阵，尺寸不超过声明的元素尺寸。
**当前（修复前）**：会得到一条宽度远超画布的一维条码。

用手机扫一下 —— 这是唯一可信的验收方式。

### 1.2 条码宽度真的受控

```bash
npm run cli -- render-test --element barcode --module-width 2 -o /tmp/b2.png
npm run cli -- render-test --element barcode --module-width 3 -o /tmp/b3.png
```

**期望**：两张图的条码宽度之比约为 2:3。
**当前（修复前）**：两张图完全相同——`widthMm` 与模块宽度都不起作用。

### 1.3 奇数模块宽度被接受

```bash
npm run cli -- render-test --element barcode --module-width 3 -o /tmp/b3.png
```

**期望**：成功。修复前会因「必须为偶数」而拒绝。

## 2. 验证工作区（US2，无需打印机）

```bash
npm run dev
```

浏览器打开 `http://localhost:5173`（或 dev 脚本输出的地址）。

| 步骤 | 期望 |
|---|---|
| 侧边栏依次点击七项 | 各开一个标签页；再次点击已开项→切换不新建 |
| 两次点击「标签设计」 | 得到两个独立设计标签页 |
| 在标签页 A 选中一个元素、缩放到 200%，切到 B 再切回 A | 选中状态与缩放比例**完好** |
| 修改后关闭标签页 | 弹出确认 |
| 修改后按 F5 | 浏览器离开确认 |
| 打开某模板后复制地址，新窗口打开 | 进入同一模板的设计页 |
| 任意页面刷新 | 恢复该页面，其余标签页不恢复 |
| 开到第 10 个标签页 | 出现流畅度提示，但仍可继续开 |

**并发冲突**（需两个窗口）：

1. 两个窗口打开同一模板。
2. 窗口 A 修改并保存 → 成功。
3. 窗口 B 修改并保存 → **被拒绝**，提示已被他处修改；
   **B 的编辑内容仍在页面上**，没有丢失。

## 3. 验证编辑器交互（US3，无需打印机）

| 步骤 | 期望 |
|---|---|
| 拖动元素 | 吸附到 dot 网格；按住 Alt 拖动则不吸附 |
| 拖动旋转手柄 | 只停在 0/90/180/270 |
| 将元素旋转 90° | 选择框贴合旋转后外形；越界提示基于新包围盒 |
| 拖角手柄缩放图片 | 宽高比不变 |
| 拖角手柄缩放文本 | 框变大而字不变形 |
| 文本内容输入换行 | 画布显示多行，行距为字号 1.2 倍 |
| 拖条码宽度手柄 | 宽度跳变而非连续；属性面板显示模块宽度（dot + mm） |
| 添加椭圆，宽高设为相等 | 得到正圆；按住 Shift 缩放保持等比 |
| 椭圆描边宽度设为大于短轴 | 渲染为实心椭圆，**不报错**，属性面板仍显示所填数值 |
| 两元素重叠，点图层面板中被压住的那个 | 该元素被选中 |
| 右键元素 | 出现删除/置顶/置底菜单 |
| 删除元素后撤销 | 元素连同属性与图层位置一并恢复 |
| 在标签页 A 撤销 | 标签页 B 的历史不受影响 |

## 4. 验证偏移与 Profile（US4）

**离线部分**：

| 步骤 | 期望 |
|---|---|
| 在打印机页设置偏移 | 保存在打印机上；切换 Profile 不改变它 |
| 编辑 Profile 的纸张尺寸与四边边距 | 边距支持联动与分别设定 |
| 在编辑器选择该 Profile | 画布尺寸自动变为该纸张尺寸，**元素位置不动** |
| 上一步后按撤销 | 画布尺寸还原 |
| 观察画布 | 边距区域有视觉标记，但仍可在其中放置元素 |
| 不选 Profile | 不绘制边距，并提示尚未选择 |

**迁移验证**（关键，离线可执行）：

```bash
npm run test -- migration
```

**期望**：迁移前后全部既有模板的渲染哈希**逐像素一致**。
这条断言是 FR-078 的直接体现，比人工翻看模板可靠得多。

**需要打印机的部分**：打印校正页、量测偏差、填入后复打验证。
