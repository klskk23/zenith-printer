# 契约：界面行为

**Feature**: `002-web-workspace-editor`

本文约定的是**可测试的界面行为**，不是视觉稿。视觉见 `docs/frontend-design-v2.md`。

---

## 1. 标签页

| 行为 | 契约 |
|---|---|
| 打开 | 七个侧边栏条目全部以标签页打开；已打开者再次点击→切换，不新建 |
| 多开 | 「标签设计」可开多个，各自独立状态 |
| 保持挂载 | 未激活的标签页 **MUST** 保持挂载；切回时选中元素、缩放、滚动位置、撤销历史完整 |
| 关闭 | 有未保存修改时先确认 |
| 视觉符号 | 「当前激活」与「关闭」**MUST** 使用不同符号 |
| 未保存标记 | 标题旁显示 |
| 软上限 | 达到 10 个时提示流畅度可能下降，**MUST NOT** 阻止继续开启 |
| 溢出 | 标签栏横向滚动，**MUST NOT** 压缩内容区 |

---

## 2. 路由

| 路径 | 含义 |
|---|---|
| `/` | 首页 |
| `/design/new` | 未保存的空白设计 |
| `/design/:templateId` | 从模板打开的设计 |
| `/templates` `/printers` `/queue` `/history` `/settings` | 对应页面 |

**契约**

- 地址 **MUST** 反映当前激活的标签页。
- 路由 **MUST NOT** 决定哪些标签页存在——只决定激活哪一个。
- 刷新恢复地址所指的**那一个**标签页；其余不恢复。
- `/design/new` 刷新后为一张新空白画布。
- 存在未保存修改时，离开/刷新 **MUST** 触发浏览器离开确认。

---

## 3. 画布交互

| 操作 | 契约 |
|---|---|
| 拖动 | 吸附到 dot 网格；按住 **Alt** 不吸附 |
| 旋转 | 只能停在 0/90/180/270；拖动旋转手柄时吸附到最近直角 |
| 缩放（图片、二维码） | 保持宽高比 |
| 缩放（文本） | 只改文本框尺寸，**MUST NOT** 拉伸字形；字号独立调整 |
| 缩放（条码） | 高度自由；宽度吸附到 `moduleWidthDots × moduleCount` 的可达值 |
| 缩放（矩形、椭圆） | 自由改宽高；按住 **Shift** 锁等比 |
| 删除 | 右键菜单，或 Delete 键 |
| 图层 | 右键菜单或图层面板的置顶/置底 |
| 选择框 | **MUST** 贴合旋转后的实际外形 |

**吸附计算** **MUST** 基于画布的整数 dot 网格，
**MUST NOT** 逐元素独立从 mm 换算（宪章「单位约定」）。

---

## 4. 标尺与缩放

- 水平与垂直**双轴**；主刻度 mm，次刻度按 dot 细分。
- 刻度 **MUST** 随缩放变化且标注值正确。
- 提供「适应窗口」与连续缩放；**不使用**固定档位。
- 标尺为纯展示，**不提供**拖出参考线。

---

## 5. 撤销与重做

- 覆盖**全部**改变设计内容的操作，含画布尺寸变更。
- 每个设计标签页独立的历史，互不干扰。
- **MUST NOT** 持久化；关闭标签页即丢弃。
- 栈深度上限 50。
- 连续拖拽 **MUST** 合并为一步（拖拽结束时入栈）。

---

## 5b. 打印机偏移

- 以「上 / 右 / 下 / 左」四个方向输入呈现。
- 相对的两个方向**互斥**：填写「上移」时「下移」归零，反之亦然。
- 存储为两个有符号的 dot 值（水平、垂直），换算在前端完成。

---

## 6. Profile 与画布

- 选择 Profile 时画布尺寸**自动**变为该 Profile 的纸张尺寸。
- **MUST NOT** 自动移动、重排或缩放已有元素。
- 该尺寸变更 **MUST** 可撤销。
- 越界元素按警告级标记，不阻断。
- 边距以视觉区别方式绘制，**MUST NOT** 阻止在其中放置元素。
- 未选择 Profile 时不绘制边距，并提示尚未选择。

---

## 7. 错误呈现

- 服务端返回的 `what` / `why` / `next` **MUST** 原样显示，
  **MUST NOT** 由前端改写措辞——同一故障不得有两套说法。
- **越界 MUST NOT 禁用打印动作**，仅以警告标记（FR-067）。
- 批量提交前 MUST 列出全部越界行及原因，由使用者决定是否继续（FR-090）。
- 仍然阻断的只有「任务根本无法执行」的情形（如条码内容不合码制、二维码超容量），
  这类问题改数据即可解决，与越界不同。
- 服务端断开时：顶部状态转警示，**且**内容区顶部显示说明性横幅。

---

## 8. 本地化

- 界面文字与服务端错误文案 **MUST** 同步切换语言。
- 语言偏好存于浏览器本地，刷新后保持。
- **MUST NOT** 在代码中硬编码面向使用者的文案。
