## Clarifications

### Session 2026-08-21

- Q: 两个标签页（或两个人）打开同一模板并先后保存时如何处理？ → A: 保存时比对版本，冲突则拒绝并提示重新加载（乐观并发）
- Q: 同时打开的标签页是否设上限？ → A: 软上限 10 个，达到后提示但不阻止
- Q: 椭圆描边宽度大于其短轴时如何处理？ → A: 自动退化为填充，不报错（与矩形描边规则一致）
- Q: 撤销/重做覆盖哪些操作？ → A: 覆盖全部编辑操作；撤销栈随标签页独立存在，不随模板持久化
- Q: 批量打印中部分标签越界时如何处理？ → A: ~~整批拒绝~~ → **修订：照常打印整批，提交前列出全部越界行**（见下方修订记录）

### Session 2026-08-21（修订）

- 修订：越界 **不再阻断打印**，改为仅警告（FR-067、FR-089 – FR-091、SC-015）。
  原结论为「整批拒绝」，使用者复核后改为「只给警告」——
  判断权交给使用者，系统负责把越界说清楚而不负责替其取舍。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 二维码与条码正确打印 (Priority: P1)

标签设计者在标签上放置一个二维码，设定内容与尺寸，打印出来得到一个**可以扫描的二维码**，
其尺寸与设计时看到的一致。同样，条码的宽度设定必须真实影响打印结果。

**Why this priority**: 当前二维码元素会被打印成一维条码，且宽度远超标签边界——
用户每打印一张就浪费一张纸，且无法察觉原因（预览与打印结果一致地错）。
这是唯一一条**正在造成实际损失**的缺陷，且不依赖任何界面改造即可交付。

**Independent Test**: 无需任何界面改动。设计一张含二维码的标签，导出渲染结果，
用扫码设备读取打印件即可完整验证。

**Acceptance Scenarios**:

1. **Given** 一张标签上有一个 15×15 mm 的二维码元素，内容为一段网址，
   **When** 渲染该标签，
   **Then** 输出的图形是二维码矩阵而非一维条码，且其外接尺寸不超过声明的 15×15 mm。
2. **Given** 同一个二维码元素设定了纠错等级，
   **When** 渲染该标签，
   **Then** 生成的二维码采用所设定的纠错等级。
3. **Given** 一张标签上有两个条码元素，分别设定不同的模块宽度，
   **When** 渲染该标签，
   **Then** 两个条码各自按自己的模块宽度渲染，互不影响。
4. **Given** 一个条码元素的模块宽度设为奇数（如 3 dot），
   **When** 渲染该标签，
   **Then** 渲染成功，且所有条边缘落在整数 dot 边界上。
5. **Given** 一个条码元素的模块宽度设为 1 dot，
   **When** 保存或渲染，
   **Then** 系统拒绝并说明模块宽度下限为 2 dot（低于扫描规范）。

### User Story 2 - 多标签工作区 (Priority: P2)

使用者打开系统，从侧边栏进入不同功能页；每个功能以标签页形式打开，
可以**同时打开两张标签设计**并在它们之间来回切换而不丢失编辑状态。
把当前页面的地址发给同事，同事打开后看到同一个页面。

**Why this priority**: 这是本次重构的骨架，其余页面都挂在它上面。
但它不修复任何正在发生的损失，因此排在缺陷修复之后。

**Independent Test**: 打开两个设计标签页、切换、关闭、刷新，全程不需要打印机在线。

**Acceptance Scenarios**:

1. **Given** 使用者在首页，**When** 从侧边栏点击「标签设计」，
   **Then** 新增一个标签页并激活，首页标签页仍在。
2. **Given** 已打开一个标签设计，**When** 再次从侧边栏点击「标签设计」，
   **Then** 新增第二个独立的设计标签页，两者的编辑内容互不干扰。
3. **Given** 已打开多个标签页，**When** 在它们之间切换，
   **Then** 每个标签页恢复到离开时的完整编辑状态（选中元素、缩放比例、滚动位置）。
4. **Given** 某个设计标签页有未保存修改，**When** 关闭该标签页，
   **Then** 系统先行确认，取消则不关闭。
5. **Given** 某个设计标签页有未保存修改，**When** 刷新或关闭浏览器页面，
   **Then** 浏览器给出离开确认提示。
6. **Given** 使用者正停留在某个模板的设计页，**When** 复制地址并在新的浏览器窗口打开，
   **Then** 打开的是同一个模板的设计页。
7. **Given** 使用者停留在任意页面，**When** 刷新，
   **Then** 恢复该页面（且仅该页面），其余标签页不恢复。
8. **Given** 打印队列中有 3 个待处理任务，**When** 查看侧边栏，
   **Then** 「打印队列」条目显示数量徽标 3；任务清零后徽标消失。
9. **Given** 服务端断开，**When** 查看界面，
   **Then** 顶部状态指示转为警示状态，且内容区顶部出现说明性横幅。

### User Story 3 - 标签编辑器交互增强 (Priority: P3)

标签设计者在画布上摆放元素：拖动时能对齐到网格，可以旋转直角，
可以等比缩放，可以写多行文字，可以画椭圆，可以在元素重叠时通过图层列表选中被压住的那个，
可以右键删除，并且看得见标尺和当前缩放比例。

**Why this priority**: 这些是设计效率的核心，但每一项都可以在骨架完成后独立增量交付。

**Independent Test**: 完全在编辑器内验证，不需要打印机，也不需要保存。

**Acceptance Scenarios**:

1. **Given** 画布已显示，**When** 观察画布四周，
   **Then** 水平与垂直两个方向都有标尺，主刻度为毫米。
2. **Given** 缩放比例变化，**When** 观察标尺，**Then** 刻度间距随之变化，标注值仍然正确。
3. **Given** 一个元素被选中，**When** 拖动它，
   **Then** 位置吸附到 dot 网格；按住 Alt 拖动时不吸附。
4. **Given** 一个元素被选中，**When** 拖动其旋转手柄，
   **Then** 旋转角度只能停在 0°、90°、180°、270°。
5. **Given** 一个已旋转 90° 的元素，**When** 观察其选择框与越界提示，
   **Then** 选择框贴合旋转后的实际外形，越界判定基于旋转后的包围盒。
6. **Given** 一个图片元素被选中，**When** 拖动角手柄缩放，**Then** 宽高比保持不变。
7. **Given** 一个文本元素被选中，**When** 拖动角手柄缩放，
   **Then** 文本框尺寸改变而字形不被拉伸变形；字号通过属性面板独立调整。
8. **Given** 一个文本元素，**When** 在内容中输入换行，
   **Then** 画布与打印结果都呈现为多行，行距为字号的 1.2 倍。
9. **Given** 一个条码元素，**When** 拖动其宽度手柄，
   **Then** 宽度吸附到「模块宽度 × 模块数」的可达值，且模块宽度不低于 2 dot。
10. **Given** 一个条码元素被选中，**When** 查看属性面板，
    **Then** 模块宽度以 dot 与毫米两种单位显示，宽度毫米值为只读派生值。
11. **Given** 元素面板，**When** 添加一个椭圆元素，
    **Then** 画布出现椭圆，可自由改变宽高；按住 Shift 缩放时锁定等比。
12. **Given** 两个元素重叠，**When** 在图层面板点击被压住的那个，
    **Then** 该元素被选中。
13. **Given** 一个元素被选中，**When** 使用置顶 / 置底，
    **Then** 该元素的绘制顺序移到最前 / 最后，图层面板顺序同步更新。
14. **Given** 一个元素，**When** 右键点击它，
    **Then** 出现包含「删除」「置顶」「置底」的菜单。
15. **Given** 使用者刚刚删除了一个元素，**When** 执行撤销，
    **Then** 该元素连同其原有属性与图层位置一并恢复。
16. **Given** 两个标签设计同时打开，**When** 在其中一个执行撤销，
    **Then** 另一个的编辑历史不受影响。

### User Story 4 - 设备偏移校正与纸张配置 (Priority: P4)

操作者给打印机换了一卷纸，发现打印内容整体偏移。他打印一张校正页，
量出偏差，在打印机页面填入上下左右的偏移量，之后所有任务都自动修正。
纸张的尺寸与边距记录在 Profile 中，选用某个 Profile 时画布自动变为该纸张的尺寸。

**Why this priority**: 换纸是常规操作，偏移是必然发生的；但在偏移功能就位前，
用户仍可通过调整元素位置绕开，因此不是最紧急的。

**Independent Test**: 偏移值的存储与生效可用离线渲染验证；校正页的实际打印需要设备。

**Acceptance Scenarios**:

1. **Given** 一台已添加的打印机，**When** 在打印机页面设置上下左右偏移量，
   **Then** 偏移保存在**该打印机**上，切换 Profile 不改变它。
2. **Given** 打印机设置了偏移量，**When** 打印任意标签，
   **Then** 打印内容整体按该偏移平移。
3. **Given** 一台打印机，**When** 点击「打印校正页」，
   **Then** 系统先行确认（因为会消耗纸张），确认后打印一张带刻度与中心十字的标签。
4. **Given** 一个 Profile，**When** 编辑它，
   **Then** 可设置纸张宽高与上右下左四个边距，边距默认为 0 且支持四值联动输入。
5. **Given** 编辑器中已选择打印机，**When** 选择一个 Profile，
   **Then** 画布尺寸自动变为该 Profile 的纸张尺寸，已有元素位置保持不变。
6. **Given** 因切换 Profile 导致部分元素越界，**When** 观察画布，
   **Then** 越界元素被标记为警告，用户可撤销这次尺寸变更。
7. **Given** 已选择带边距的 Profile，**When** 观察画布，
   **Then** 边距区域以斜纹阴影绘制，但仍可在其中放置元素。
8. **Given** 未选择任何 Profile，**When** 观察画布，
   **Then** 不绘制边距，并给出未选择 Profile 的提示。
9. **Given** 升级前已存在的、带偏移值的 Profile，**When** 系统升级完成，
   **Then** 偏移值迁移到所属打印机，且迁移过程记录在日志中。

### User Story 5 - 界面偏好与双语 (Priority: P5)

使用者把界面切换为英文，此后**包括错误提示在内**的全部文案都是英文。
他还可以设定新建标签的默认尺寸、默认字体、深浅色主题等偏好，这些设定只影响他自己。

**Why this priority**: 提升可用性但不阻塞任何工作流；且中文用户是主要使用者。

**Independent Test**: 切换语言后遍历各页面与一个故意触发的错误，检查文案语言一致。

**Acceptance Scenarios**:

1. **Given** 界面为中文，**When** 在设置页切换为英文，
   **Then** 界面文字变为英文，且刷新后保持英文。
2. **Given** 界面为英文，**When** 触发一个服务端错误（如打印机不可达），
   **Then** 错误的三要素（发生了什么 / 为什么 / 下一步）也是英文。
3. **Given** 使用者在设置页修改新建标签的默认尺寸，**When** 新建一张标签设计，
   **Then** 画布采用该默认尺寸。
4. **Given** 使用者更换浏览器，**When** 打开系统，
   **Then** 偏好回到默认值（偏好只存于本地浏览器）。
5. **Given** 设置页，**When** 浏览全部设置项，
   **Then** 不存在任何会影响其他使用者的服务端配置项。

### Edge Cases

- **条码内容绑定可变字段时宽度未知**：模块数随内容长度变化，设计时无法确定最终宽度。
  设计时以字段示例值估算并提示「实际宽度随内容变化」；**打印前必须对每一张标签的
  真实内容重新执行越界检查**，而不是只对示例值检查一次。
- **批次中部分标签越界**：**照常打印整批**，但提交前列出全部越界行。
  批次内的标签通常有对应关系（一批货、一批资产编号），
  整批被挡住比打出几张需要重打的更难收拾；越界内容被裁切后仍可人工判断，
  由使用者决定是否接受。
- **切换 Profile 后画布变小导致大量元素越界**：不自动重排、不自动缩放，
  标记警告并允许撤销。
- **同一台打印机的多个 Profile 携带不同偏移值**（迁移场景）：取默认 Profile 的值迁移到打印机，
  被丢弃的值记入迁移日志。
- **元素完全被另一元素覆盖**：只能通过图层面板选中。
- **旋转 90° / 270° 后元素超出标签**：越界检查必须使用旋转后的包围盒，否则漏报。
- **未保存的新建设计刷新页面**：地址无法表达未保存内容，恢复为空白画布；离开前已提示。
- **标签页数量过多**：标签栏需可横向滚动，不得挤压内容区。
  达到 10 个时提示流畅度可能下降，但不阻止继续开启——真正的瓶颈取决于各标签页中
  标签的复杂度而非数量本身，硬性上限会在用户正需要时挡住他。
- **同一模板被同时编辑**：包括同一人在两个标签页中打开同一模板的情形。
  后保存者被拒绝，其编辑内容保留在页面上，由使用者自行重新加载后重做。
  **不做加锁**——无认证意味着无法识别锁的持有者，忘记关闭的标签页会永久锁死模板。
- **服务端在编辑过程中断开**：编辑不中断（纯本地操作），但保存与打印动作给出明确失败提示。
- **二维码内容过长超出所选纠错等级容量**：拒绝并说明原因，不静默截断。
- **椭圆描边宽度大于其短轴**：自动退化为填充的椭圆，不报错。
  与矩形描边「按半个描边宽度内缩」的既有规则一致，无需为椭圆定义特例；
  属性面板仍显示使用者填写的原值，不做静默钳制。

## Requirements *(mandatory)*

### Functional Requirements

#### 渲染正确性（US1）

- **FR-001**: 系统 MUST 将二维码元素渲染为二维码矩阵，而非任何一维条码。
- **FR-002**: 二维码的渲染尺寸 MUST 不超过该元素声明的宽高。
- **FR-003**: 二维码 MUST 使用元素上设定的纠错等级。
- **FR-004**: 条码的模块宽度 MUST 是元素自身的属性，使同一标签上的不同条码可以采用不同模块宽度。
- **FR-005**: 条码的实际渲染宽度 MUST 等于「模块宽度 × 模块数」，其中模块数由内容与码制决定。
- **FR-006**: 系统 MUST 接受任意不小于 2 的整数模块宽度（含奇数），并拒绝小于 2 或非整数的值。
- **FR-007**: 在任何被接受的模块宽度下，条码所有条的边缘 MUST 落在整数 dot 边界上。
- **FR-008**: 二维码内容超出所选纠错等级容量时，系统 MUST 拒绝并说明原因，不得静默截断。

#### 工作区外壳（US2）

- **FR-009**: 系统 MUST 提供七个功能入口：首页、标签设计、模板库、打印机、打印队列、打印历史、设置。
- **FR-010**: 全部七个入口 MUST 以标签页形式打开；已打开的入口再次点击时切换而非新建。
- **FR-011**: 使用者 MUST 能同时打开多个标签设计标签页，各自维护独立的编辑状态。
- **FR-012**: 切换标签页 MUST 保留离开时的编辑状态，包括选中元素、缩放比例与滚动位置。
- **FR-013**: 每个标签页 MUST 可关闭；有未保存修改时关闭 MUST 先确认。
- **FR-014**: 「当前激活」与「关闭」MUST 使用不同的视觉符号，不得混用。
- **FR-015**: 有未保存修改的标签页 MUST 在标题处显示未保存标记。
- **FR-016**: 存在未保存修改时，离开或刷新页面 MUST 触发浏览器离开确认。
- **FR-017**: 标签栏 MUST 在标签页过多时可横向滚动，不得压缩内容区。
- **FR-018**: 侧边栏「打印队列」条目 MUST 显示待处理任务数徽标，数量为 0 时不显示。
- **FR-019**: 顶部 MUST 显示服务端连接状态；断开时 MUST 同时在内容区顶部显示说明性横幅。

#### 模板并发编辑（US2）

- **FR-079**: 模板 MUST 携带版本标记，每次成功保存后变更。
- **FR-080**: 保存模板时，若其版本标记与载入时不一致，系统 MUST 拒绝保存。
- **FR-081**: 拒绝保存时 MUST 说明该模板已被他处修改，并提供重新加载的途径。
- **FR-082**: 拒绝保存 MUST NOT 丢弃使用者当前的编辑内容。
- **FR-083**: 已打开的标签页达到 10 个时，系统 MUST 提示继续开启可能影响编辑流畅度。
- **FR-084**: 该提示 MUST NOT 阻止使用者继续开启新的标签页。

#### 地址与深链（US2）

- **FR-020**: 浏览器地址 MUST 反映当前激活的标签页。
- **FR-021**: 从模板打开的设计页 MUST 拥有可分享的地址，他人打开后进入同一模板的设计页。
- **FR-022**: 刷新页面 MUST 恢复地址所指的那一个标签页；其余标签页不恢复。
- **FR-023**: 未保存的新建设计 MUST 有可表达的地址，刷新后恢复为一张空白画布。
- **FR-024**: 未激活但已打开的标签页 MUST 保持其编辑状态，不得因地址变化而被销毁。

#### 首页（US2）

- **FR-025**: 首页 MUST 展示每台打印机的在线状态、队列运行/暂停状态与待处理任务数。
- **FR-026**: 首页 MUST 展示打印机的耗材余量；对无法上报余量的机型，MUST 明确显示「本机型无法上报」而非留空。
- **FR-027**: 首页 MUST 展示最近使用的 6 个模板，并提供进入模板库的入口。
- **FR-028**: 首页 MUST 展示最近 5 条打印记录；失败的记录 MUST 提供重新提交入口。
- **FR-029**: 点击首页的打印机卡片 MUST 打开打印机页并定位到该设备。

#### 画布、标尺与缩放（US3）

- **FR-030**: 编辑器 MUST 提供水平与垂直两个方向的标尺，主刻度为毫米，次刻度按 dot 细分。
- **FR-031**: 标尺刻度 MUST 随缩放比例变化，且标注值始终正确。
- **FR-032**: 编辑器 MUST 提供「适应窗口」与连续缩放，不使用固定档位。
- **FR-033**: 拖动元素时位置 MUST 吸附到 dot 网格；按住 Alt 时 MUST 不吸附。
- **FR-034**: 标尺 MUST 为纯展示，不提供拖出参考线的功能。

#### 元素操作（US3）

- **FR-035**: 元素旋转 MUST 只能取 0°、90°、180°、270°，拖动旋转手柄时吸附到最近的直角。
- **FR-036**: 元素的选择框与越界判定 MUST 基于旋转后的实际包围盒。
- **FR-037**: 图片与二维码缩放 MUST 保持宽高比。
- **FR-038**: 文本缩放 MUST 只改变文本框尺寸，不得拉伸字形；字号 MUST 为独立可调属性。
- **FR-039**: 条码 MUST 支持自由调整高度；宽度 MUST 吸附到可达的量化值。
- **FR-040**: 矩形与椭圆 MUST 支持自由调整宽高；按住 Shift 时 MUST 锁定等比。
- **FR-041**: 系统 MUST 提供图层面板，列出全部元素并反映绘制顺序。
- **FR-042**: 图层面板的选中状态 MUST 与画布选中状态双向同步。
- **FR-043**: 使用者 MUST 能将元素置顶或置底；不要求支持任意顺序拖拽重排。
- **FR-044**: 右键点击元素 MUST 弹出包含删除、置顶、置底的菜单。

#### 撤销与重做（US3）

- **FR-086**: 系统 MUST 支持撤销与重做，覆盖全部改变设计内容的操作，
  包括移动、缩放、旋转、新增、删除、修改属性与变更画布尺寸。
- **FR-087**: 每个标签设计标签页 MUST 拥有独立的撤销历史，互不干扰。
- **FR-088**: 撤销历史 MUST NOT 随模板持久化；关闭标签页后历史即丢弃。

#### 元素类型（US3）

- **FR-045**: 系统 MUST 提供椭圆元素，以包围盒（位置 + 宽高）描述，支持描边宽度、填充与直角旋转。
- **FR-046**: 正圆 MUST 通过宽高相等的椭圆表达，不引入独立的圆形元素类型。
- **FR-047**: 椭圆的描边 MUST 使其外边缘与声明的包围盒重合。
- **FR-085**: 椭圆描边宽度达到或超过其短轴时，MUST 渲染为填充的椭圆，
  MUST NOT 报错，且 MUST NOT 修改使用者填写的描边宽度数值。
- **FR-048**: 文本 MUST 支持多行，以内容中的显式换行符分行。
- **FR-049**: 系统 MUST NOT 按文本框宽度自动折行。
- **FR-050**: 多行文本的行距 MUST 固定为字号的 1.2 倍。
- **FR-051**: 系统 MUST NOT 提供独立的「时间」元素类型；打印时刻的时间通过可变字段机制表达。

#### 打印机偏移与校正（US4）

- **FR-052**: 打印机偏移 MUST 存储在打印机上，而非 Profile 上，
  并 MUST 以打印点（dot）为单位存储为水平、垂直两个有符号值。
- **FR-092**: 偏移 MUST 以「上 / 右 / 下 / 左」四个方向输入呈现；
  相对的两个方向 MUST 互斥——填写其中一个时另一个归零。
  换纸后使用者看到的是「内容偏上了」，让其填「下移 2」比要求换算成负数更直接。
- **FR-053**: 切换 Profile MUST NOT 改变打印机的偏移量。
- **FR-054**: 打印任意标签时 MUST 按打印机的偏移量整体平移内容。
- **FR-055**: 系统 MUST 提供「打印校正页」功能，输出带刻度与中心十字的标签供人工量测。
- **FR-056**: 打印校正页 MUST 先行确认，与普通打印遵循相同的消耗确认规则。
- **FR-057**: 打印机页 MUST 说明「每次更换纸卷后都可能需要重新校正」。

#### 纸张 Profile（US4）

- **FR-058**: Profile MUST 记录纸张宽度与高度。
- **FR-059**: Profile MUST 记录上、右、下、左四个边距，默认均为 0。
- **FR-060**: 边距输入 MUST 支持四值联动（一处修改同步四边）与分别设定两种方式。
- **FR-061**: 在编辑器中选择 Profile 时，画布尺寸 MUST 自动变为该 Profile 的纸张尺寸。
- **FR-062**: 画布尺寸因选择 Profile 而变化时，系统 MUST NOT 自动移动、重排或缩放已有元素。
- **FR-063**: 画布尺寸变更 MUST 可撤销。
- **FR-064**: 边距区域 MUST 以视觉区别的方式绘制，且 MUST NOT 阻止在其中放置元素。
- **FR-065**: 未选择 Profile 时 MUST NOT 绘制边距，并 MUST 提示尚未选择 Profile。
- **FR-066**: 系统 MUST NOT 在本期实现标签间距设置，相关行为采用默认值。

#### 越界检查（US3、US4）

- **FR-067**: 越界 MUST NOT 阻断打印。系统 MUST 以警告方式标记越界，
  并允许使用者照常提交与打印；超出标签边界的内容按既有规则被裁切。
- **FR-068**: 条码内容绑定可变字段时，系统 MUST 在设计阶段以示例值估算宽度并提示实际宽度会变化。
- **FR-069**: 打印前系统 MUST 对每一张标签的真实内容重新执行越界检查。
- **FR-089**: 批次中部分标签越界时，系统 MUST 照常打印整个批次，
  MUST NOT 因越界而拒绝或跳过任何一张。
- **FR-090**: 提交前 MUST 列出每一个越界的数据行及其具体原因，供使用者判断是否仍要打印。
- **FR-091**: 越界明细 MUST 随任务一并记录，可在打印历史中回看。

#### 设置与本地化（US5）

- **FR-070**: 设置页 MUST 只包含影响本浏览器的偏好，MUST NOT 包含任何影响其他使用者的服务端配置。
- **FR-071**: 设置页 MUST 提供：语言、新建标签默认尺寸与分辨率、默认字体、尺寸显示单位、主题、队列轮询间隔、关闭标签页是否总是确认。
- **FR-072**: 系统 MUST 支持中文与英文两种界面语言。
- **FR-073**: 切换语言后，服务端返回的错误文案 MUST 同步为所选语言。
- **FR-074**: 界面偏好 MUST 持久化于本地浏览器，刷新后保持。
- **FR-075**: 面向使用者的文案 MUST 全部经由本地化层输出，MUST NOT 硬编码于代码中。

#### 数据迁移（US4）

- **FR-076**: 升级时，已有 Profile 上的偏移值 MUST 迁移到其所属打印机。
- **FR-077**: 同一打印机的多个 Profile 偏移值不一致时，MUST 采用默认 Profile 的值，并将被丢弃的值记入日志。
- **FR-078**: 迁移 MUST NOT 导致已有模板或历史记录的显示内容发生变化。

### Key Entities

- **模板（变更）**：新增版本标记，用于检测并发保存冲突。
  版本标记在每次成功保存后变更，载入时随模板一同取得。

- **工作区标签页**：一个已打开的文档或功能页。属性包括：类型（七种入口之一）、
  标题、是否有未保存修改、独立的视图状态（选中元素、缩放、滚动位置）。
  标签页集合是界面的真实状态，浏览器地址只是「当前激活的是哪一个」的投影。

- **椭圆元素**：新增的标签元素类型。以包围盒描述（位置、宽度、高度），
  带描边宽度、是否填充、旋转角。正圆是宽高相等的特例。

- **条码元素（变更）**：新增「模块宽度」属性（整数 dot，不小于 2）。
  「宽度」由「模块宽度 × 模块数」派生；内容绑定可变字段时，模块数在打印时才确定。

- **文本元素（变更）**：内容可含显式换行符，呈现为多行；行距固定为字号的 1.2 倍。

- **打印机（变更）**：新增水平与垂直物理偏移量，描述「这台机器当前的走纸位置」。
  每次更换纸卷都可能需要重新校正。

- **打印纸张 Profile（变更）**：新增纸张宽高与四边边距；移除偏移量（迁往打印机）。
  一个 Profile 代表「这台打印机 + 当前这卷纸」。

- **界面偏好**：单个浏览器的本地设定集合，不影响其他使用者，不在服务端存储。

- **图层顺序**：元素的绘制先后顺序。本期只需支持将单个元素移到最前或最后。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 二维码标签的扫描成功率不低于 99%（当前为 0%，因为渲染出的根本不是二维码）。
- **SC-002**: 条码标签的扫描成功率不低于 99%，在所有被接受的模块宽度下均成立。
- **SC-003**: 设计者能同时打开两张标签设计并来回切换 10 次，编辑内容与视图状态零丢失。
- **SC-004**: 从打开系统到开始编辑一张新标签，不超过 3 次点击。
- **SC-005**: 设计者能在 30 秒内完成「换纸后校正偏移」的全过程（打印校正页除外的操作部分）。
- **SC-006**: 元素拖动后的最终位置 100% 落在 dot 网格上（未按 Alt 时）。
- **SC-007**: 旋转 90° 或 270° 的元素，其选择框与越界判定的误差为 0。
- **SC-008**: 界面切换为英文后，随机抽查 20 处文案（含至少 3 处错误提示），英文比例 100%。
- **SC-009**: 编辑器预览与实际打印结果的元素位置偏差不超过 1 dot。
- **SC-010**: 数据迁移后，已有模板与历史记录的渲染结果与迁移前逐像素一致。
- **SC-011**: 打印前的越界检查能捕获 100% 的「可变字段导致条码超宽」情形。
- **SC-013**: 并发保存同一模板时，先保存者的修改被静默丢弃的比例为 0%。
- **SC-014**: 同时打开 10 个标签设计时，元素拖动仍保持流畅（无可感知延迟）。
- **SC-015**: 含越界标签的批次，提交前 100% 列出全部越界行；使用者知情后仍可一次提交完成，无需逐张排查。
- **SC-012**: 默认测试套件可在无任何物理打印机的情况下完整运行并通过。

## Assumptions

- **沿用既有约束**：本功能在既有的 001-label-design-print 之上增量演进。
  局域网内使用、无身份认证、单进程部署、毫米为存储单位等前提不变。
- **无认证仍是前提**：因此设置页只放本地偏好；任何全局配置继续由部署层管理，只有能登入主机的人才可更改。
  空跑开关尤其不进界面——其价值就在于不会被顺手关掉。
- **不做自动折行**：浏览器与服务端渲染器的字体度量不完全一致，按宽度自动折行会导致
  预览与打印在不同的字上换行。这与「设计预览与打印结果由同一套渲染规则产生」的既有保证直接冲突。
- **不做参考线**：标签版面小，收益不足以抵消复杂度。
- **不做标签间距**：本期采用默认值。
- **不做任意图层拖拽排序**：元素数量通常在个位数，置顶/置底已够用。
- **模块宽度下限 2 dot 来自扫描规范**：203 dpi 下 2 dot = 0.25 mm，是 Code 128 的常用 X 尺寸；
  规范下限约 0.19 mm。此下限与渲染能力无关——1 dot 完全可以渲染，只是扫不出来。
- **仅支持中英双语**：若日后加入日文或韩文，前端所用的字体子集覆盖不到，需要另行调整子集策略；
  服务端的完整字体不受影响。
- **偏好存于本地浏览器**：因无认证，无法做到「跟着用户走」。换浏览器回到默认值可接受。
- **校正页需要人工量测**：系统不具备自动检测偏移的能力。
- **地址只承载一个标签页**：分享地址时对方只会看到那一个页面，这是可接受的取舍。
- **越界只警告不阻断**：越界的判断权交给使用者而非系统。
  系统负责**把话说清楚**（列出全部越界行及原因），不负责替使用者做取舍。
  这与既有的偏移裁切策略一致——超出画布的内容静默裁切并上报裁切区域，
  而不是用错误挡住使用者。
- **撤销覆盖全部操作**：FR-063 要求画布尺寸变更可撤销，这已隐含撤销栈的存在。
  只对单一操作可撤销会让撤销键的行为无法预测，因此统一覆盖全部编辑操作。
  右键删除（FR-044）没有确认步骤，尤其依赖撤销作为安全网。
- **撤销历史不持久化**：随标签页存在，关闭即丢弃。持久化会增大模板体积而收益有限。
- **标签页上限为软性提示**：FR-024 要求未激活标签页保持挂载，因此每张设计常驻一份状态。
  不设上限会让性能退化变得无法解释（「越用越卡」却不知原因）；
  设硬上限又会误伤真正需要多开的场景。10 个是提示阈值，不是限制。
- **并发冲突采用乐观策略**：局域网内使用者数量有限，冲突罕见。
  因此选择「保存时检测」而非「打开时加锁」——无认证环境下锁无法可靠释放。
