# Quickstart: 标签工作流与说明文字清理

**Feature**: `006-label-print-flow`

## 启动

```bash
npm run dev            # 服务 + Vite
npm test               # 逻辑 + 界面两个项目
npm run typecheck && npm run lint
```

不需要真打印机。要验「打印」页的卡片，加一台假地址的打印机并探测失败即可（未探测态也是要验的状态）。要验行选择，导入一份 CSV。

---

## 第 1 步：底座（步条与地址）

**看**：

1. 打开任意标签 → 顶栏是 ① 标签 — ② 设计 — ③ 打印 — ④ 确认，右端是标签名与尺寸；没有返回箭头。
2. 地址栏依次试 `/labels/{id}`、`/labels/{id}/print`、`/labels/{id}/confirm`：步条的当前步跟着变。
3. 在「打印」页点步条的 ② → 回编辑器；点 ④（还没选打印机）→ 点不动。
4. 直接打开 `/labels/{id}/confirm` → 地址被换回 `/labels/{id}/print`。

**测**：`routes.test.ts`、`flow.test.ts`、`step-bar.dom.test.tsx`、`render-smoke.dom.test.tsx`（九个落点）。

---

## 第 2 步：打印与确认两页

**看**：

1. 画廊上一张标签的「打印」→ 落 `/labels/{id}/print`，没有对话框。
2. 打印机是卡片：型号、dpi、能否上报余量、是否已探测都在卡片上；选一台，它的默认打印参数自动选上。
3. 绑了数据源的标签在最后一节选行（勾选 / 区间 / 全选），表格下面没有任何控件。
4. 底部动作条：`上一步` … `每行份数 − 1 +` │ `3 张 · 约 4 秒` · `继续`；改份数，张数立刻变。
5. 「确认」页：清单 + 大数字；按「确认打印」→ 同页变成 ✓ 已加入队列、任务编号、三个出口。
6. 「再打一次」→ 回「打印」页，打印机与参数还在，勾选清空。
7. 「确认」页画出这张标签（服务端渲染），写着「第 1 张，共 N 张」；绑了数据源且不止一行时
   有「展开全部 N 张」，展开后每页十张、可翻页、被裁的自己标红。没绑数据源时没有这个按钮。
8. 整个路径上没有「打印会消耗标签纸」，也没有打印头示意图。

**测**：`print-step.dom.test.tsx`、`confirm-step.dom.test.tsx`、`print-submit.dom.test.tsx`、`flow.test.ts`、`row-selection-controls.dom.test.tsx`（沿用）。

---

## 第 3 步：设计页衔接

**看**：

1. 编辑器顶栏只有步条——没有返回箭头，没有打印机、打印参数两个下拉，也没有「打印」按钮。
2. 撤销/重做在画布头部，和缩放、当前选中同一行。
3. 底部：`保存` `另存为` … `继续`。
4. 改一处不保存按「继续」→ 直接到「打印」页；提交打出来的是改动后的内容；服务器上的版本没变。
5. 改一处不保存，点步条的 ① 标签或侧栏 → 问「保留这些修改吗？」；而在「打印」页选一台机器**不算**修改，走开不会被问。
6. 从「打印」页点步条 ② 回来 → 那处修改还在。

**测**：`editor-toolbar.dom.test.tsx`（改写）、`editor-back.dom.test.tsx`（改写）、`flow-dirty.dom.test.tsx`。

---

## 第 4 步：裁切说明

**看**：

1. 把一个元素拖出标签边界，走到「确认」页 → 页头右端多一行红字，说清超出多少毫米；按「打印」照样能打。展开逐张看时，被裁的那几张自己标红。
2. 没超界时那一行不出现。
3. 选一台标签装不下的打印机 → 同一行说明超出打印头多少毫米。
4. 选一台没探测过的打印机 → 说明无法判断范围；「继续」不可按（未探测本来就不能打）。

**测**：`clip-summary.test.ts`、`confirm-clip.dom.test.tsx`。

---

## 第 5 步：旧地址

**看**：

1. `/design/{id}?preset={presetId}` → 落「打印」页，地址变 `/labels/{id}/print?preset=…`，打印机/参数/份数已按预设摆好，没有自动出纸。
2. `/design/{id}` → 落「设计」页。`/templates` → 落画廊。
3. 预设指的打印机已删 → 打印机留空并说明原因。

**测**：`preset-link.dom.test.tsx`（改写）、`routes.test.ts`。

---

## 第 6 步：说明文字

**看**：

1. 数据源页：标题旁一个 `?`，正文没有「一个数据源就是一张表……」；点 `?` → 地址可选中 + 「复制」。
2. 打印参数表单：「黑白分界」旁的 `?`，鼠标停上去或 Tab 聚焦都能读到原来那段。
3. 改名弹窗里没有「名称只是给人看的……」。
4. 删除/清理的确认框、断连横幅、版本冲突、列消失这些，一字不少。

**测**：`hint-tiers.test.ts`、`hint.dom.test.tsx`、`data-source-hint.dom.test.tsx`、`terminology.test.ts`（沿用）。

---

## 第 7 步：画廊页头

**看**：页面上没有「标签」标题；页头一行是队列状态 + 搜索 + 导出全部 + 导入 + 新建标签；页头与瓦片之间有淡出分隔线；瓦片动作顺序是打印、改名、导出、删除。

**测**：`gallery.dom.test.tsx`（改写）、`labels-header.dom.test.tsx`。
